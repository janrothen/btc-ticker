How to connect a Waveshare E-Ink display to a Raspberry Pi

In this guide, you'll learn how to wire a Waveshare 2.13" e-paper display to your Raspberry Pi and run the BTC Ticker software so it shows the live Bitcoin price.

What you'll need

  • Raspberry Pi (any model with a 40-pin GPIO header; this guide uses a Pi 4)
  • Waveshare 2.13" e-ink display V2 (epd2in13) with 8-pin HAT connector or loose wire harness — $14.99 on waveshare.com
  • Jumper wires (if your display comes with a loose harness rather than a HAT)
  • MicroSD card with Raspberry Pi OS based on Debian Trixie (Python 3.13 or newer) installed
  • Internet connection on the Pi to fetch prices

What you are going to build

Raspberry Pi 4 with the Waveshare 2.13" display showing the live BTC price

1. Enable SPI on the Raspberry Pi

The e-ink display communicates over the SPI bus, which is disabled by default. Enable it with raspi-config:

sudo raspi-config

Navigate to Interface Options → SPI → Yes, then reboot:

sudo reboot

2. Wire the display to the GPIO header

The display has 8 pins. Connect them to the Pi's 40-pin header as follows. Use either the physical pin numbers or the GPIO labels — but don't mix them. The full reference is in the Waveshare wiki.

Pin labels printed on the back of the display

Display pin Physical pin GPIO / function
VCCPin 173.3 V power
GNDPin 20Ground
DINPin 19GPIO 10 / MOSI
CLKPin 23GPIO 11 / SCLK
CSPin 24GPIO 8 / CE0
DCPin 22GPIO 25
RSTPin 11GPIO 17
BUSYPin 18GPIO 24

Raspberry Pi 40-pin GPIO header — raspberrypi.com

Tip: after connecting, most pins cluster between physical pins 17–24, with the RST wire reaching back to pin 11. Double-check that pin before powering on.

3. Install btc-ticker

On your Raspberry Pi, as the user the ticker should run as, clone the repository and run the installer:

git clone https://github.com/janrothen/btc-ticker
cd btc-ticker
./deploy/install.sh

The installer sets up everything in one go: the system packages, SPI, the gpio and spi groups, a Python virtual environment with the display drivers, and a systemd service that starts the ticker on every boot. It talks to the GPIO pins through gpiozero's lgpio backend, so no GPIO daemon is needed. It is safe to run again; ./deploy/install.sh --help lists the options.

If the installer has just enabled SPI, it asks you to reboot. Run sudo reboot, then run ./deploy/install.sh once more to start the service.

4. Check that it's running

The display shows the Bitcoin logo on startup, then refreshes the price every 5 minutes. Check the service and follow its log:

systemctl status btcticker
journalctl -u btcticker -f

To stop the ticker and disable auto-start:

sudo systemctl disable --now btcticker

5. Upgrade

To update to the latest version, pull the changes and rerun the installer:

git pull && ./deploy/install.sh

Manual installation steps, migrating from older pigpio-based installs and rollback are described in deploy/systemd/README.md.
